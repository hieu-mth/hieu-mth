# Copilot Instructions

Follow rules defined in:

- /docs/engineering/guidelines.md
- /docs/engineering/architecture.md

---

## When generating code

- Do not hardcode data inside components
- Use service layer for data access
- Keep components small and readable
- Use semantic HTML (section, h1, h2, ul, li)
- Follow existing folder structure
- Avoid unnecessary complexity
- Do not introduce external UI libraries

---

## Priorities

1. Clarity
2. Maintainability
3. Consistency

---

## Avoid

- Over-engineering
- Deeply nested logic
- Large components (>150 lines)
- Mixing UI and business logic

---

## Goal

Generate production-quality code, not demo code
